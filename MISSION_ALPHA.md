## Briefing

The three buoys are in transit, each following a different vector. THE REACH cannot pursue all three simultaneously. The constellation must choose which to retrieve first.

**Buoy Alpha** (navigation data, unknown coordinate system):
- Closest trajectory — retrieval window: 4 hours
- Contains navigation data in a coordinate system that does not reference Earth
- First translation attempt shows the reference point is *not* Sol
- Risk: if the buoy enters the debris field, data is lost permanently

**Buoy Beta** (audio recording, 47s, 6-min repeating pulse):
- Intermediate trajectory — retrieval window: 8 hours
- Contains a sound that repeats every 6 minutes
- Ambient temperature at recording: -220°C
- Depth reading: impossible

**Buoy Gamma** (cryptographic key, no lock found):
- Farthest trajectory — retrieval window: 14 hours
- Contains a single cryptographic key
- Checksum matches annotation Voss wrote minutes before signal loss
- No lock has been found for this key
