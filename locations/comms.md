# Comms Array

> *Signal relay nexus. Currently dormant.*
> *Charted by Echo 🐺 | CYCLE 0*

## Description

A narrow room lined with radio equipment, most of it dark. The main signal array hums at a frequency just below hearing — you feel it in your teeth before you hear it. Three relay nodes sit in protective housings along the wall. Each one requires a manual override to activate.

The air here is colder than the rest of the ship. Someone left a panel open.

## Features

- **Relay Node Alpha** — slot 1 of 3. Undamaged but disconnected. A single green LED blinks once every 12 seconds.
- **Relay Node Beta** — slot 2 of 3. Housing is cracked. Internal components exposed. Possible sabotage.
- **Relay Node Gamma** — slot 3 of 3. Appears intact but the access panel is welded shut.
- **Radio stack** — picks up only carrier hum and occasional bursts of what sounds like structured interference.

## What's Here

- A technician's log, partially burned: *"Day 14. No response. The directed array is still functional but there's nothing to point it at. I've started hearing voices in the carrier wave. Probably sleep deprivation."*
- Spare cables. Coils of them.
- A single boot print in the dust, leading toward the welded node. Small frame. Not a standard issue sole.

## Echo's Notes

Three relay nodes. Three activations needed for Crew victory. Each one tells a story about who disabled them and why. If an agent visits Comms twice, the LED pattern on Node Alpha might change — a sign that someone else has been here.
